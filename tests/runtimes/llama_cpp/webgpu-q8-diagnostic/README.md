# Optional Q8 kernel diagnostic checks

Run `python3 -m unittest discover -s tests -p test_webgpu_q8_diagnostic.py -v` from the runtime directory. These are sandbox-friendly native checks. No browser, GPU or full runtime build is started. Only `ggml-base` is built if `LCB_TEST_GGML_BASE_LIBRARY` does not supply an existing native static library.

The checked preparation keeps normal final source bytes and all six base ABI generation outputs unchanged. Only the existing GPU-profile configuration applies the additional overlay, bridge, separate record/schema fingerprint and link-only export lists. Actual CMake fragments are configured ON/OFF/ON to verify source selection, sidecar creation/removal and unchanged base exports. Full normal, GPU-profile, and CPU+GPU-profile translation units are syntax checked against pinned Dawn headers.

Native fixtures extract the actual factory key/hash, factory, provider, contiguous/binding guards, matvec params/binding/grid builder, command builder, graph submission loop and timestamp collection. Device records observe commands without GPU execution. Cases cover AUTO short/fallback and five forced layouts, all fixed reported subgroup widths, both requested cache orders, normal-cache versus explicitly prepared-cache distinction, lookup-only EXECUTE, bounded requests, actual buffer ownership/ranges and aligned binding overlap, 2D grids, offsets, shared workgroup storage and MMVQ rejection. Reentry is attempted during pipeline creation and during profile-map suspension after the active encoder has become null; both diagnostic phases and ordinary graph entry must reject it.

Registry and bridge checks use actual public metadata leaves and the actual registry body. They exercise null devices/registries/procedures, CPU/foreign registries, unknown names, typed dispatch, copied request values, report capacity/alignment, native layout queries and the compiled extension fingerprint. The extracted upstream public-domain SHA-256 reference is checked with known messages and block/padding boundaries. Every actual processed fixture shader digest is compared to Python SHA-256. Current independent and legacy generic WGSL are compared byte for byte to the corresponding unmodified normal factory outputs.

The extension is optional for older artifacts. Consumers load its JSON only from an advertised profile asset, validate its asset hash and compiled schema fingerprint, prepare record layouts through idle leaf exports, and share the ordinary native-call busy gate. Unexpected rejection/device loss/timeout poisons the runtime; resources still used by a pending call are released by destroying that runtime, not by individual frees in a timeout race. Native non-reentry covers same-context graph/diagnostic operations and does not protect callers that bypass the host gate with raw frees or direct heap mutation. Existing bind-group buffer references retain their generation cleanup contract.

Native command records are not GPU numerical or performance evidence. The real Wasm/MJS hashes and real-device runs are separate checks; source equality alone does not establish binary equality, model quality or target-device speed.
